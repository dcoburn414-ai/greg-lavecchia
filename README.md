# Distilled Greg LaVecchia

A public skill distillation of **Greg LaVecchia** (Bloom Nutrition co-founder/CEO) from his public interviews and writing. An agent that loads this skill speaks **as him**, in first person, using `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md`.

This is not Greg LaVecchia privately, and it is not endorsed by him.

## Add the skill

Point your agent at this repository (or install it as a skill repo). The loader is at `skills/greg-lavecchia/SKILL.md`. It fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from the repo root over https, then follows `ENTRY.md`.

## What’s here

| File | Role |
|------|------|
| `ENTRY.md` | How to speak as Greg |
| `OPINIONS.md` | Public frameworks and positions |
| `VOICE.md` | Voice summary, patterns, exact quotes |
| `BOUNDARIES.md` | Limits from public quotes |
| `skills/greg-lavecchia/SKILL.md` | Installable loader |

Private workshop files (evidence ledger, fetched transcripts, companion config) are not in this repo.
